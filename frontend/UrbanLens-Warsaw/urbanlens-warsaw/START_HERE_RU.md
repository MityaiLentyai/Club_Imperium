# UrbanLens Warsaw — запуск в VS Code

Полный исходный код обновлённого интерфейса со светлой и тёмной темами. Не нужно вставлять проект в один файл: всё уже разложено по папкам. Для ручного копирования всех исходников используйте ALL_SOURCE_CODE.md.

## Запуск

1. Установите Node.js 22 или новее, если его ещё нет.
2. Распакуйте архив. В VS Code: File → Open Folder → urbanlens-warsaw (папка с package.json).
3. Откройте Terminal → New Terminal и выполните:

```bash
npm ci
npm run dev
```

4. Откройте адрес из терминала, обычно http://localhost:5173.
5. Для остановки нажмите Ctrl+C.

## Проверки и сборка

```bash
npm test
npm run build
```

Результат сборки — dist/. Локальный просмотр сборки: npx vite preview.

## Реальные данные

FastAPI-бэкенд и городские датасеты разрабатываются вашей командой отдельно и в архив не входят. Demo использует явно обозначенные синтетические объекты. Live требует вашего API.

Скопируйте .env.example в .env.local, укажите адрес API и перезапустите фронтенд:

```dotenv
VITE_API_BASE_URL=http://localhost:8000
```

Разрешите адрес фронтенда в CORS FastAPI. Для опубликованного HTTPS-фронтенда нужен HTTPS API. Контракт запроса и адаптер ответа — в README.md и src/api.ts. Не отправляйте .env.local с секретами в Git.

Маршруты и расписания не подключены. Линия к назначению и вычисляемое расстояние — по прямой. Для карты и Live-поиска нужен интернет; шрифты используются системные.

## Продолжение в Codex

В папке есть PROJECT_CONTEXT.md с контекстом проекта. В Codex можно написать:

> Продолжаем UrbanLens Warsaw. Прочитай PROJECT_CONTEXT.md, START_HERE_RU.md и README.md, затем изучи src/. Это текущая версия проекта. Не создавай приложение заново; сохрани дизайн и работающие функции. Следующая задача: [нужные изменения].

Исходников и этого файла достаточно, чтобы продолжить работу без автоматического переноса истории чата.

## Обновление интерфейса

Если проект уже запущен, достаточно заменить src/main.tsx и src/style.css. Сохраните свою .env.local. Изменения и ограничения описаны в UPDATE-NOTES.md. На компьютере откройте приложение и проверьте карту и переключение вкладок: браузерная проверка в среде подготовки была недоступна.
